# Food Macro Prediction

A data science project focused on predicting macronutrient content in foods using machine learning techniques. This project analyzes food composition data to create predictive models for protein, carbohydrates, and fat content.

## Project Overview

This project includes:
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model development and training
- Performance evaluation and visualization

## Notebook Structure

The main notebook `food_macro_analysis.ipynb` contains:
1. Data Import and Preprocessing
2. Exploratory Data Analysis with Visualizations
3. Feature Engineering and Selection
4. Model Training and Evaluation
5. Results and Conclusions

## Requirements

- Python 3.8+
- Key Libraries:
  - pandas
  - numpy
  - scikit-learn
  - matplotlib
  - seaborn
  - plotly

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Showmo35/Food-Macro-Prediction.git
   ```
2. Install required packages:
   ```bash
   pip install pandas numpy scikit-learn matplotlib seaborn plotly
   ```
3. Open `food_macro_analysis.ipynb` in Jupyter Notebook or VS Code
4. Run the cells sequentially to reproduce the analysis
